## 길이 — 요청 '정상속도 약 3분' 대비
대본 1,598자(음절 약 1,860)를 TTS 원본 287.6초로 읽은 분량이라, 3:00에 맞추려면 약 1.6배(초당 10음절 이상)가 필요해 알아듣기 어렵다.
→ **1.3배(초당 약 8.6음절) + 쉼 축소**로 3분 37초. 3분 안쪽이 꼭 필요하면 대본을 15~20% 줄여 다시 녹음하는 것이 맞다.

## 만드는 순서 (`scratchpad` 작업 폴더 기준, V1 도구 그대로)
```
ffmpeg -i src.wav -af atempo=1.3 -ac 1 -ar 48000 sped.wav           # ① 1.3배
venv/bin/python tighten.py                                          # ② 0.30초 넘는 쉼만 40%로 (52곳, 7.0초)
ffmpeg loudnorm 2-pass → +0.5dB → voice.wav                         # ③ -14.0 LUFS, 피크 -4.0 dBFS, 213.8초
venv/bin/python asr.py → asr.json (= asr_clean.json)                # ④ 최종 음성으로 단어 시각
venv/bin/python subs.py                                             # ⑤ chunks.txt 정렬 → subs.json/.srt (일치 98.5%, 0.9초 미만 0)
venv/bin/python crop_products.py                                    # ⑥ 라인업 사진에서 럭셔리 크림 한 개 잘라내기
venv/bin/python build.py v && venv/bin/python build.py h            # ⑦ 장면 → comp/comp_v.html, comp_h.html (+ out/bounds_*.json)
bash render_all.sh v && bash render_all.sh h                        # ⑧ 4구간 병렬 렌더 → 이어 붙이기 → 음성(0.6초 여백·끝 1초 페이드)
node contact.mjs v cs.png 5.8,14.5,...  /  node frames.mjs h fr/h 74,179 0.5  /  node pair.mjs out.png a.png b.png
node poster.mjs v poster_9x16_v2.jpg 5.6 && node poster.mjs h poster_16x9_v2.jpg 5.6   # 자막 없는 포스터
```
앱 화면 캡처(`capture*.mjs`)는 V1과 같은 Demo 빌드 캡처(예시 데이터만)를 다시 쓴다.
